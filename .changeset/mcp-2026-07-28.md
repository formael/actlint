Read servers speaking the MCP 2026-07-28 specification

actlint now reads MCP servers that speak the 2026-07-28 protocol revision, alongside every
previously supported revision. The protocol era is negotiated automatically on each scan — no flag
or configuration is required.

- Captures record the negotiated protocol revision as provenance.
- On stdio, era detection may briefly start the server command a second time to probe it before the
  tool list is read.
- The bundled MCP SDK moved to `@modelcontextprotocol/client` v2 (from `@modelcontextprotocol/sdk`
  v1). The scan surface is unchanged: actlint still reads tool declarations only and never invokes
  a tool.
- The v2 subtree carries OAuth machinery — `jose` and `pkce-challenge` — that actlint does not
  call. It is code you accept in the tree, not code actlint runs; the scanner authenticates but
  never exercises the OAuth flow.
- Existing captures, baselines, and reports are unaffected — no findings change.
